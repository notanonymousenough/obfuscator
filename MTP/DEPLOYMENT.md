## Обновление: публичный вход через DE1

Владелец выбрал релей. DNS AZ1 теперь **159.89.12.205**, DDNS timer включён со статическим адресом релея. Обратный SSH-туннель восстановился после принудительного разрыва (`NRestarts=1`). `mtg doctor` теперь проходит все проверки, включая SNI/DNS. Доступ к AZ1 через SSH-config с pipe проверен. С DE2 подтверждён внешний TLS/HTTP маршрут через DE1 на AZ1. Итоговая схема и команды: [RELAY.md](RELAY.md). DE1 дополнительно получает XHTTP на том же 443 через SNI.

Ниже приведено итоговое состояние с учётом релейного входа.

## Выполнено на сервере

- ОС: Debian 13.7, Raspberry Pi 3 ARM64, hostname `obfuscator-az1`, LAN `192.168.0.194`.
- SSH переведён с 22 на **2222**. Новые подключения проверены на этапе двух портов и после закрытия 22. Эффективные параметры: `PermitRootLogin no`, `PasswordAuthentication no`, `KbdInteractiveAuthentication no`, `PubkeyAuthentication yes`, `AllowUsers deploy`.
- Сначала использовался пятиминутный автоматический откат. Во время задержки проверки разрешений он сработал и безопасно вернул 22; затем перенос выполнен повторно, проверен и зафиксирован. Защитный timer после успешной проверки остановлен.
- UFW активен: входящие по умолчанию запрещены, разрешены **2222/tcp** и **443/tcp** (IPv4/IPv6). Временное разрешение 22 удалено.
- Установлены mtg **2.2.8**, nginx, Certbot/Cloudflare DNS plugin, fail2ban, unattended-upgrades. BBR/fq настроены. Синхронизация времени включена.
- `obfuscator-mtp.service` включён и **active/running**, слушает TCP 443. Выполняется как отдельный системный пользователь `mtg`, без x-ui.
- nginx включён и работает только как локальный fallback на **127.0.0.1:8443**. Внешний HTTP 80 не нужен для DNS-01.
- Сертификат `az1.obfuscator.funsociety.dev` получен через DNS-01. Срок: **27.10.2026 15:59:22 UTC — 25.01.2027 15:59:21 UTC**.
- `certbot.timer` включён. Установлен deploy hook, проверяющий nginx и выполняющий reload после обновления сертификата.
- `cloudflare.token` и `cloudflare.ini`: **0600 root:root**. Временный staging-файл токена удалён. В проект токен не копировался; используется существующий игнорируемый `.cloudflare`.

## Итог внешнего доступа и ограничения

- DNS A AZ1 — **159.89.12.205**, Cloudflare DNS-only. DDNS timer включён; рабочий конфиг публикует фиксированный IP релея, не CGNAT адрес AZ1.
- Туннель `obfuscator-az1-tunnel` включён. Закрытый ключ остаётся на AZ1. Reverse listeners на DE1 доступны только как localhost:9443 и localhost:12222.
- На DE1 порт 443 обслуживает HAProxy: SNI AZ1 → reverse tunnel → mtg AZ1; SNI DE1 → nginx → отдельный XHTTP Xray DE1. Старый MTProto DE1:8888 сохранён.
- Из внешнего DE2 проверен полный публичный TLS/HTTP маршрут AZ1 после включения SNI-маршрутизации.
- SSH через DE1 с pipe проверен и вернул hostname `obfuscator-az1`.
- Обычный прямой вход на AZ1 по-прежнему невозможен из-за CGNAT. Роутер Tenda не менялся.
- Реальная MTProto-сессия телефона и прохождение из РФ ещё не проверены. Проверки TLS и mtg doctor не заменяют клиентский тест.
- Исходящий Xray/SOCKS chaining AZ1 → DE2 пока не включён: mtg выходит в Telegram напрямую из AZ1. Новый XHTTP DE1 — самостоятельный параллельный сервис.
- Звонки через MTProto не добавлены: мобильная галочка относится к SOCKS5. Для звонков нужен поддерживаемый SOCKS5 либо VPN/TUN-клиент.

## Управление и локальная проверка

Доступ:

```sh
ssh user@192.168.0.192 'ssh -p 2222 deploy@192.168.0.194'
```

В root-shell либо с sudo:

```sh
systemctl stop obfuscator-mtp
systemctl start obfuscator-mtp
systemctl status obfuscator-mtp
journalctl -u obfuscator-mtp -n 50 --no-pager
/usr/local/lib/obfuscator/access.py --server 192.168.0.194
```

Последняя команда покажет приватную ссылку для проверки Telegram из локальной сети. Secret включён в ссылку; её не нужно публиковать. Для уже настроенного публичного входа использовать `access.py` без `--server`, тогда адресом будет домен.

Следующий шаг — проверка реального Telegram-клиента по публичному домену, затем тест из РФ. Полная схема и команды внешнего SSH находятся в RELAY.md.
