## de2: Xray в Docker за nginx

### Действующая схема по доступным файлам и процессам

`клиент → de2:443 / nginx с TLS → 127.0.0.1:8443 / Xray VLESS XHTTP → freedom / IPv4 → интернет`

- nginx, Docker, containerd работают. Процесс `xray` выполняется с UID 65532.
- `xray-docker.service` включён, состояние **active/exited** штатно для `Type=oneshot` с `RemainAfterExit=yes`.
- Сервис запускает `docker compose up -d` из `/opt/xray`. В compose указаны `ghcr.io/xtls/xray-core:latest`, `restart: always`, `network_mode: host`; `./config.json` монтируется в `/etc/xray/config.json:ro`.
- В `/opt/xray/config.json`: один VLESS-вход `in-gateway` на **127.0.0.1:8443**, транспорт **XHTTP**, один клиент. На внутреннем участке `security=none`; внешний TLS завершает nginx.
- nginx слушает 80 и 443 по IPv4/IPv6. Для `de2.obfuscator.funsociety.dev` настроен `grpc_pass grpc://127.0.0.1:8443`, также есть каталог сайта `/var/www/decoy`.
- На 80 запрос `/` получает **301** на HTTPS. На 443 запрос `/` получает **200**. Подлинность сертификата проверена стандартным TLS-клиентом, согласован TLS 1.3.
- Сертификат Let's Encrypt для `de2.obfuscator.funsociety.dev`: выдан **03.09.2026 21:03:41 UTC**, действителен до **02.12.2026 21:03:40 UTC**. `certbot.timer` активен; успешность будущего продления и deploy hooks не проверена.
- Выход `direct` — `freedom` с `domainStrategy=UseIPv4`; `geoip:private` направлен в `blackhole`. Выходного туннеля на другой узел в этом конфиге нет.

Это подтверждает работающие процессы, внешний HTTPS и наличие конфигурации шлюза, но **не заменяет полноценный VLESS/XHTTP-сеанс**. Docker API недоступен пользователю deploy, поэтому фактический digest/версия контейнера, health и внутренние логи не проверены.
